# Development entry points

This file replaces the original Slidev starter example. It is not a lecture entry.

- Edit course materials under `lessons/weekN/`.
- Use `README.md` for single-week build commands.
- Run `npm run build:course` to rebuild every teaching week.
- Run `npm run check:course` before syncing materials to the website.
- See `ENVIRONMENT.md` for the tested toolchain and notebook environment guidance.
