# MPS311/439 Machine Learning — course material sources

All ten lessons are Quarto: Notes (`.qmd`, Chinese and English), RevealJS slides and lab worksheets. Lesson 4 is the reference implementation for Lessons 3–10:

- `lessons/lessonN/lecture/figures/note/` — `build_numbers.py` (every number), `build_note_figures.py` (`--lang en`, `--slides`), `build_widgets.py` (self-contained HTML widgets, JS syntax checked), `i18n_en.py`.
- `lessons/lessonN/lecture/` — `note_zh.qmd`, `note_en.qmd`, `slides/slide.qmd`.
- `lessons/lessonN/lab/` — `lab_worksheet.qmd`, `build_solution.py` (fills the blanks, runs the notebook, asserts every check value).
- `lessons/shared/tools/` — `note_lint.py`, `deck_review.py` (slide screenshots and overflow), `note_shots.py` (Note screenshots for the student reviewer).

The production workflow is `lessons/COURSE_MATERIAL_WORKFLOW.md`; the reviewers are in `../.claude/agents/`.

## UoS 2025 versions (Slidev)

Each lesson's 2025 deck is kept in `lessons/lessonN/archive/uos-2025/` with its built `dist/` and `slide-export.pdf`. The Slidev toolchain (`package.json`, `package-lock.json`, `vite.config.ts`, `components/`, `pages/`, `snippets/`, `scripts/patch-slidev-paths.mjs`) stays here so that those decks can be rebuilt:

```bash
npm ci          # installs Slidev; the postinstall patch fixes paths with spaces
npm run build:standalone -- lessons/lesson6/archive/uos-2025/lecture/slide.md --out dist --base './'
npx slidev export lessons/lesson6/archive/uos-2025/lecture/slide.md --output lessons/lesson6/archive/uos-2025/lecture/slide-export.pdf --executable-path "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
```

`node_modules/` is not kept; reinstall it with `npm ci` when needed.
